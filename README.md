# Ovara

A comprehensive personal wellbeing platform for activity, nutrition, fitness goals, self-care, habits and everyday routines.

**Your everyday, in better balance.**

## First pass

Responsive frontend with overview, activity, nutrition, routines and journal sections. Interactions use illustrative in-memory sample data. Authentication, database persistence, notifications and device integrations are not connected yet.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4 (Vite plugin)
- React Router
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Product principles

- Personal wellbeing, not medical diagnosis or treatment.
- Inclusive of different fitness levels and personal goals.
- Private by default; sensitive personal records require explicit access controls.
- International-ready: units, locale, dates and time zones should be user preferences.
